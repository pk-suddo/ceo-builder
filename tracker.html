☁️ Cloud Sync — Supabase

Connect Supabase to sync your data across all browsers and devices. Your data stays in your own Supabase project.

Quick setup (2 min):
  1. Go to supabase.com → create a free project
  2. In the SQL Editor, run:
    CREATE TABLE tracker_data ( id TEXT PRIMARY KEY DEFAULT 'main', state JSONB, updated_at TIMESTAMPTZ DEFAULT now() );
  3. Go to Settings → API Keys → copy Project URL + Publishable key (listed under "Publishable and secret API keys")
  4. Paste them below and click Connect
